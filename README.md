 Chocolate Shipments Data Analysis – Power BI

📌 Project Overview

This project analyzes chocolate shipment data using Microsoft Power BI to understand sales performance, shipment quantities, order statuses, products, geographical regions, and sales team performance.

The dashboard helps users explore shipment trends and identify business insights through interactive visualizations and data analysis.

🎯 Project Objectives

- Analyze total sales amount and boxes shipped.
- Track shipment status, including delivered and cancelled orders.
- Compare product and category performance.
- Analyze sales across countries and geographical regions.
- Evaluate sales performance by salesperson and team.
- Identify shipment trends over time.

🛠️ Tools & Technologies

- Power BI Desktop – Dashboard development and data visualization
- Power Query – Data cleaning and transformation
- DAX – Measures and calculations
- Microsoft Excel – Dataset storage and preparation
- Data Modeling – Relationships between shipment, product, geography, salesperson, and calendar data

📂 Dataset Description

The dataset contains three worksheets:

1. Shipments

Contains shipment transaction details:

- ShipmentID
- SPID – Salesperson ID
- PID – Product ID
- GID – Geography ID
- Shipdate
- Amount
- Boxes
- Order_Status

2. Calendar

Contains date-related information:

- Calendar date
- Month number and month name
- Year
- Weekday number and weekday name

📊 Dashboard Features

- KPI cards for key shipment and sales metrics
- Sales and shipment trend analysis
- Product and category comparisons
- Geographical performance analysis
- Order status breakdown
- Salesperson and team performance
- Interactive slicers and filters

Note: Dashboard features should be adjusted to match the visuals actually included in your report.

🔄 Project Workflow

1. Import the Excel dataset into Power BI Desktop.
2. Clean and transform data using Power Query.
3. Create relationships between the relevant tables.
4. Develop DAX measures for sales and shipment metrics.
5. Build interactive charts, tables, and KPI cards.
6. Validate the results and publish the report to Power BI Service.

📈 Key Business Insights

The dashboard can help identify:

- Products and categories contributing the most sales.
- Regions with stronger shipment performance.
- The proportion of delivered and cancelled orders.
- Sales trends across months and years.
- Differences in performance between salespeople and teams.
